## 📖 Sobre o Projeto

Este é um **aplicativo educacional interativo** desenvolvido para ensinar o Plano Cartesiano de forma visual e prática. O projeto combina teoria, interatividade e aplicações no mundo real, especialmente na área de **robótica**.

### 🎯 Público-alvo
- Estudantes do Ensino Médio e Técnico
- Cursos de Desenvolvimento de Sistemas e automação
- Entusiastas de robótica e programação
- Professores que buscam material didático interativo

---

## ✨ Funcionalidades

### 📊 **Plano 2D Interativo**
- Clique no gráfico para marcar pontos
- Visualização de coordenadas em tempo real
- Histórico de pontos com rótulos
- Modo **"Desafio"** para praticar a localização de pontos
- Exibição de coordenadas ao passar o mouse

### 🌐 **Plano 3D (Three.js)**
- Visualização tridimensional dos eixos X, Y e Z
- Interação com a câmera (arrastar para rotacionar, scroll para zoom)
- Eixos coloridos com setas e rótulos
- Representação da origem (0,0,0)
- Aplicações práticas em robótica

### 🎮 **Atividades e Desafios**
- **Desafio 1:** Partindo da origem até o ponto (2, 3)
- **Desafio 2:** Cálculo de distância entre pontos
- **Desafio 3:** Posicionamento 3D na robótica
- **Desafio 4:** Identificação de quadrantes com coordenadas negativas
- Sistema de "revelar resposta" para aprendizado ativo

### 📚 **Teoria + Robótica**
- Explicação completa do Plano Cartesiano
- Aplicações práticas em robótica
- Exemplos com robôs aspiradores, drones, braços robóticos e carros autônomos
- Desafios finais com resolução passo a passo

## 🎯 Como Navegar

### Aba "2D Clássico"
- **Teoria:** Explicação dos eixos, quadrantes e coordenadas
- **Interação:** Clique no gráfico para marcar pontos
- **Desafio:** Clique em "Desafio" e encontre o ponto solicitado

### Aba "3D Interativo"
- **Teoria:** Explicação do eixo Z e aplicações em robótica
- **Interação:** Arraste para rotacionar, scroll para zoom
- **Exemplo:** Visualize a posição de um drone em 3D

### Aba "Atividades"
- Resolva os 4 desafios propostos
- Clique em "Ver Resposta" para conferir seu raciocínio
- Use o botão "Novo Desafio" para praticar mais

### Aba "Teoria + Robótica"
- Resumo completo da teoria
- Aplicações práticas em robótica
- Desafio final com resolução detalhada

## 🎓 Para Professores

### Sugestões de Uso em Sala de Aula

| Atividade | Duração | Objetivo |
|-----------|---------|----------|
| **Introdução teórica** | 5 min | Explicar o Plano Cartesiano |
| **Exploração 2D** | 5 min | Alunos marcam pontos no gráfico |
| **Desafio 2D** | 10 min | Encontrar pontos solicitados |
| **Exploração 3D** | 5 min | Visualizar eixos e coordenadas 3D |
| **Atividades** | 20 min | Resolver os 4 desafios |
| **Discussão em grupo** | 10 min | Compartilhar estratégias |

### Habilidades Desenvolvidas
- ✅ Localização de pontos no plano cartesiano
- ✅ Identificação de quadrantes
- ✅ Cálculo de distância entre pontos
- ✅ Compreensão de coordenadas 3D
- ✅ Aplicações práticas em robótica
- ✅ Pensamento crítico e resolução de problemas

## 🔧 Personalização

### Alterar Cores
As cores são controladas por variáveis CSS no `:root`:

```css
:root {
    --primary-color: #1f4a7a;    /* Azul principal */
    --primary-light: #79a5e2;    /* Azul claro */
    --secondary-color: #27ae60;  /* Verde */
    --danger-color: #e74c3c;     /* Vermelho */
}
```

### Adicionar Novos Desafios
Edite a seção de atividades no HTML:

```html
<div class="atividade-item">
    <div class="pergunta">
        <i class="fas fa-question-circle"></i>
        Desafio 5: Seu novo desafio aqui
    </div>
    <button onclick="revelarResposta('resp5')">
        Ver Resposta
    </button>
    <div id="resp5" class="resposta">
        Resposta do desafio
    </div>
</div>
```
